SO, HOW DO I USE THESE CDS?

For your convenience, we've provided an HTML browser formatted index. On each CD, you can open the HTML folder and click on the INDEX.HTML file. This will open the browser, which gives you three options:

1.) Click on the CATALOG icon (Large Catalog for DISK 1 and Medium and Small for DISK 2). Next, you'll see a list of thumbnail images of the textures. Click on any of these and a full-sized texture will be displayed in your browser. If you like, you can click on FILE>SAVE AS and save the texture to a project folder or other location.
2.) Click on the PHOTOS icon to see a list of photograph/background thumbnail images. Follow the same procedure as in #1, above to display and save the photographs.
3.) Click on the LOCATION LIST icon and click on TEXTURES or PHOTOS. Either option will give you a list of each texture or photograph, with a listing that tells you where the image was captured, listed by country and city.

Note that a HOME icon is listed at the bottom of each page, if you want to return to the original page. You can also use your browser's FORWARD and BACKWARD features to navigate through this extensive index.


FILE NAMING CONVENTIONS

Limited to eight characters, for compatibility on all platforms. First three or four characters -- lower-case alpha description of the texture.  Examples: "arch" for arches, "wind" for windows, etc.
A.) Next Two Character Positions  -- numeric representation of the texture in its class.  For example, "bldg01," "bldg02," etc.
B.)  Next Character Position -- This is either an upper case L, M or S for large, medium or small resolution.  The reason for uppercase is so the "L" doesn't look like the number "one."  Example: "bldg01S, wndw05L, etc."
C.) Next Character Position -- For textures, this is blank.  For bump maps, a lower case "b" is added. For example, an arch texture could be "arch04M.jpg" and the corresponding bump map is  "arch04Mb.jpg"
D.) Extension -- "jpg" in lower case 


THE INEVITABLE EXCEPTIONS - CLIP MAP NAMING

Clip maps are presented in TGA and JPG format. For the TARGA files, the same naming conventions apply as above. For the JPGs, which take two images to create a transparent effect, the first file is named according to the conventions above, and the second file (the alpha channel map) includes an "a" in the 7th character slot. For example "tran34L.jpg" for the regular image, and "tran34aL.jpg" for the alpha channel image.  We recommend using the TARGA formats, depending on what graphics program you use. Some graphics programs recognize only one shade of black (0,0,0) as transparent. Since all JPG images are dithered, the black sometimes dithers to many different shades of black, which can cause artifacts in your image. We recommend experimenting with both the TGA and JPG formats for clip maps.


BUMP MAPS

Bump maps, sometimes called elevation maps, are provided for each texture. These can add depth to your texture when applied in a 3D program. No index is provided for these.  To use a bump map, call it up from the file picker in your 3D graphics program.


ALTERNATE WAYS TO VIEW THE TEXTURES AND BUMP MAPS

An alternate and interesting way to view the textures and bumps together is to create a simple scene in your 3D program. Some artists prefer creating something as simple as a cube or a sphere. I prefer making a wall, a floor, and maybe a few simple objects like a tall cylinder or a vase. Then experiment by applying various textures and their bump maps to these meshes.


2D PRODUCTION APPLICATIONS

If you're using these textures in 2D production applications, such as ad layouts, try using the textures for lettering, patterns (backgrounds) or any other facet of your layout. If you need a larger size, try tiling these textures to make them as large as you wish - remember they are all seamlessly tileable. Also, try layering different textures at various transparency/opacity levels for a multitude of combinations.


UV MAPPING AND SUNGLASSES 

Don't confuse your sunglasses' UV rating with UV mapping in 3D programs! Different 3D programs apply textures in different ways -- it seems every program does it slightly differently. Consult your program's documentation and, if you're not already a pro, learn the art of UV mapping. As a rule, "U" refers to the way a texture is mapped horizontally onto an object and "V" refers to the vertical method. UV Repeats tell you how many times a texture will be repeated over a surface, and UV Offset allows you to adjust the horizontal or vertical placement.  Amplitude or Altitude defines the difference between the high points and low points of a bump map. Most programs also allow for you to use different methods to map textures onto your objects, such as planar, spherical, cylindrical and rectangular. Try mapping textures using these methods for the desired result. And, if you want to be really cool, go ahead and wear your sunglasses while you do your UV mapping!


TIPS, TRICKERY AND OTHER BLACK MAGIC

Some tips on using textures: try using various textures in places where you wouldn't ordinary use them. Use the textures in places where you heretofore may have used solid colors. You'd be surprised how different textures can fit into a variety of places - and while you're at it, don't forget the bump maps for the added 3D effect.  

Some tips on using bump maps: try experimenting with various bumps, using no texture.  Or, try mixing various textures with various bump maps. The results can be startling. The bump maps in this collection by itself can be a remarkable tool. Note that each 3D program handles bump maps differently. We've supplied bump maps with a nominal contrast level that is useful in most programs. If this level is too bright or dark for your particular 3D program, feel free to jack up the brightness or dim the darkness in your favorite 2D program.
